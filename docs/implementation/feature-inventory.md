# Sketch draw.io feature inventory

This is the capability inventory for the draw.io parity effort. It records what Sketch
does at one committed revision, what draw.io documents, and what is missing. It is a
planning record, not a marketing page.

**Baseline:** commit `5de2f5b` (feat(ux): text vertical position, writing direction, background/border/shadow, opacity).

Only committed code at HEAD is counted. The working tree contains uncommitted
changes and untracked files. None of that work is counted here, even when a feature
appears to exist on disk. If a row says a capability is missing, it is missing from
the baseline commit, not necessarily from the working tree.

## Working tree progress (2026-10-26)

The M1 sidebar work on `agent/drawio-features` is present but uncommitted, so the
statuses below still describe `5de2f5b`. The working tree now has:

- Context-sensitive tabs: Diagram and global Style with no selection; Style, Text, and
  Arrange with a selection. The active tab is kept only when it is valid for the new
  selection, otherwise the first valid tab is chosen.
- Diagram settings stored per page: grid visibility, grid size, custom grid color,
  solid page background, paper size and orientation, global shadow and sketch defaults,
  connection arrows, connection points, guides, autosave, and page metadata.
- Page view is a session-only view option and starts off. It draws the paper, shadow,
  and outline and clips the grid to the page when enabled, but it is not saved with the
  document.
- Global Style tab: sketch and rounded toggles plus 20 scheme presets with paging.
- Element Style tab: fill modes (Auto, solid, linear and radial gradients, image),
  line visibility, dash, width and perimeter, opacity, rounded, sketch, glass, shadow,
  paged palette, JSON editing, style clipboard, and default style capture.
- Text tab: font family, size, bold, italic, underline, strikethrough, vertical text,
  alignment, vertical position, writing direction, font color, background, border,
  shadow, formatted text, opacity, clear formatting, spacing, and the label text box.
  Connector-only selections expose the same typography, alignment, wrap, color,
  background, border, shadow, and opacity controls, hide the box-only position and
  spacing rows, and edit the connector label in the text box.
- Connector labels: connectors carry one editable label centered on the midpoint of the
  routed line (straight, curved, or elbow). Double-click edits it on the canvas; the
  Text tab edits text and styling; hit testing covers the routed line and the measured
  label box; backgrounds and borders wrap the glyphs; labels follow reroutes and persist
  with the page. Dragging the label stores its normalized position along the route and a
  world-space offset, so the label can slide along the line or sit off it and still
  follow a reroute.
- Transparent line gaps: a connector label without a solid background cuts the line
  behind its text, so the characters stay readable. A solid background plate still paints
  over one continuous line. The cut is derived from the label layout (no stored state),
  follows label moves and reroutes, and reaches the canvas, sketch mode, and SVG, PDF,
  and PNG export through the shared draw ops.
- Arrange tab: z-order, size, position, angle and 90 degree rotation, flip, alignment,
  snap to grid, group and ungroup, size clipboard, lock and unlock, and structural
  actions. Arrange > Reset holds Label Positions and Waypoints for connectors, each a
  single undo step and disabled when the selection has nothing to reset.
- Reverse connector: the Arrange tab Reverse button swaps each selected connector's
  source and target bindings and reverses its waypoints in one `Reverse connector`
  transaction, matching draw.io's `turnShapes`. Arrowheads and labels stay bound to the
  line's own ends, so they visually move to the opposite end while the path stays put
  (see ADR-008).
- Line jumps: each connector stores a jump style (none, arc, gap, sharp, line) and a
  size with draw.io's defaults, and a paint-order walk feeds each connector the points
  where it crosses a connector painted below it. The hop shapes and half-gap formula
  follow `mxConnector.paintLine`; hops compose with the transparent label gap, survive
  sketch mode, and reach SVG and PDF export (see ADR-015).
- Multiple labels per connector (2026-10-27): the first label stays in the existing
  fields and second and later labels live in a per-connector list that inherits the
  connector's label style. An Add label button in the Text tab creates one with its
  placeholder selected; each label drags along or off the line with its own position
  and offset; double-clicking a label edits that label; every transparent label cuts
  the line behind its text; Reset Label Positions covers extras; and save, load, undo,
  and PNG/SVG/PDF export carry the whole list (see ADR-008).
- Auto-route around obstacles (2026-10-27): the elbow router now avoids every bindable,
  visible shape near the route, not only the two bound shapes. Obstacles are the
  shapes' world boxes with a fixed clearance, culled to the route's search
  neighborhood so the A* grid stays bounded, and their edges become grid lines the
  search paths around. A shape moved into a connector's route neighborhood reroutes
  that connector in the same transaction. Straight and curved routes are unchanged,
  matching draw.io where only orthogonal routing avoids shapes.
- Page layers (M3, 2026-10-27): every page starts with a Background layer and old pages
  get one through the v4 to v5 migration. A node stores its layer id and children inherit
  the nearest ancestor's, so a subtree paints on one layer; moving a selection writes the
  layer across whole top-level subtrees, groups and frames included. Paint order buckets
  the unchanged root list by layer first, and the canvas, hit testing, and SVG, PNG, and
  PDF export walk that order. The Layers dialog, opened from the sidebar Layers tab row,
  covers add, rename, duplicate, delete with its shapes, reorder, visibility, lock,
  select all on layer, and move the selection to a layer, each one undo step that also
  restores the layer list and next layer id. Connectors keep bindings across layers. MCP
  gets list_layers, batched layer_ops, a layer argument on create_shape, and layer
  fields on get_node_info (see ADR-009). DIA-12 waits for custom links (M6).

- Shape registry, search, quick add, and scratchpad (M4, 2026-11-05): the Library tab
  gains a fuzzy registry search with preview tiles, a scratchpad of pinned and recent
  shapes, and drag-out insertion with a ghost preview. Double-clicking empty canvas under
  the Select tool opens quick add at that point. The registry is a static set of 30
  entries in six categories; entries emit regular nodes, plain entries take the page shape
  default on insert and in previews, and insertion is one undoable layer-aware step that
  joins the frame under the point or a named parent. Autosize in the Arrange tab and on
  Alt+F hugs nested groups and gives frames 20 px of headroom. MCP gains search_shapes and
  insert_shape. Rows for CUS-07, CUS-08, CUS-09, CUS-16, and SHP-17 note the working-tree
  implementation but keep their baseline status (see ADR-010).

- draw.io import and export (M5, 2026-11-08): .drawio and .xml files import into native
  pages through an adapter that keeps page names and order, maps layers, groups, frames,
  styles, labels, and edges, and returns a report of approximations, drops, and warnings.
  The report appears in a dismissible window after an import, and imported pages can join
  the current project with their layers intact. Export writes every page as one
  uncompressed .drawio file from the inspector, the CLI, or the export API, and the
  checked-in two-page fixture reimports with the same pages, layers, and supported
  shapes. Rows for IO-15, IO-16, and IO-21 note the working-tree implementation but keep
  their baseline status (see ADR-011).

- Diagram data, links, tags, and find (M6, 2026-11-10): nodes carry an ordered metadata
  map, a custom link, a tooltip, and a tag list, all optional and skipped from the page
  file while empty. The Data tab edits them, the Edit Data dialog covers shape and page
  properties, and a page context resolves percent placeholders in labels, connector
  labels, text layers, sticky notes, frame names, and tooltips from shape, ancestor, and
  page metadata plus page name, page number, page count, file name, and date values. A
  missing value renders a visible fallback. Custom links follow by Cmd/Ctrl click or the
  Data tab Open Link button; page links switch pages and external links are limited to
  http, https, and mailto, opened through the platform opener after confirmation. Find
  searches labels, connector labels, text and sticky content, frame names, tags, tooltips,
  and metadata keys across pages with case sensitivity, regular expressions, next and
  previous stepping, and replace with one undo step per page that skips locked and hidden
  nodes. The draw.io adapter reads and writes UserObject data and a sketch-data sidecar.
  Rows for DIA-01 to DIA-09 and DOC-14 note the working-tree implementation but keep
  their baseline status (see ADR-013).

- Templates and diagram packs (M7, 2026-11-11): a validated JSON template library format
  with a format name and version, named templates carrying a category, description,
  keywords, and an optional SVG thumbnail, and pages storing ordinary nodes, root order,
  diagram settings, and layers. The browser groups templates by library, searches and
  filters by category, previews a page as vector content, and inserts one page on the
  open page or every page as new pages under one undo step, keeping layers whose names
  match. Fifteen bundled packs cover flowchart, UML class, ER, BPMN, network, floor plan,
  org chart, kanban, timeline, Gantt, C4, SysML, charts, Venn, and a three-page project
  plan, built only from native kinds and registry shapes. A node naming a registry shape
  this build lacks is reported and skipped while the rest inserts, and its bindings and
  child references are cleared. A custom folder in options loads every JSON library
  beside the bundled packs, reports unreadable files, and the open page saves back as a
  template with a thumbnail. MCP exposes list_templates and insert_template. Rows for
  GEN-06 to GEN-15 and CUS-12 to CUS-14 note the working-tree implementation but keep
  their baseline status (see ADR-010).

- Data and text generation (M8, 2026-11-11): Mermaid, CSV, SQL, and JSON text parse into
  ordinary native documents, then insert on the open page as one undo step or as a new
  project page. Mermaid covers flowcharts and sequence diagrams with warnings for
  unsupported directives. CSV detects comma, semicolon, tab, or pipe, honours quoted
  fields, and offers grid, flow, and tree layouts with an optional header and label
  column. SQL turns CREATE TABLE, table-level FOREIGN KEY, and ALTER TABLE statements
  into table frames with column rows, key markers, and bound relationships. JSON accepts
  nodes and edges, keeps coordinates only when every node has them, and otherwise uses a
  deterministic layered or grid layout. The Insert menu, command palette, and MCP
  generate_diagram tool share the same parsers and report warnings. No generator path
  makes a network request, and AI generation stays blocked. Rows for GEN-01 to GEN-03
  and GEN-05 note the working-tree implementation but keep their baseline status (see
  the ADR-011 extension).

- Search omnibox (2026-11-12): the Ctrl+K command palette now searches every diagram and
  the text inside it from one field. Alongside commands, tools, pages, layers, templates,
  generators, and library items, it lists native registry shapes as insert entries and
  diagram text from every page. Choosing a shape inserts it at the viewport center in one
  undo step; choosing a text hit switches to its page, selects the node, and zooms to it.
  Text hits reuse the find engine's fields, matching rules, labels, and previews, stay
  capped at 40 entries, and appear only for a non-empty query so opening the palette does
  not dump every label in the document. The UIX-11 row notes the working-tree
  implementation but keeps its baseline status (see the ADR-010 and ADR-013 extensions).

- Rulers and manual guides (2026-11-14): the Diagram tab gains a Rulers toggle and a
  Clear Guides button, both page settings saved with the document. Rulers draw as 18 px
  strips along the canvas top and left with 1-2-5 tick spacing and labels at the current
  zoom. Dragging out of a ruler creates a guide, dragging the line moves it, dropping it
  on a ruler deletes it, and each gesture is one undo step; a drag that ends on the ruler
  records Delete guide rather than Move guide. Manual guides take priority over center
  alignment, equal spacing, and grid snapping for moves, and a resize snaps only the
  dragged edge to the nearest guide. Guides paint as blue lines in the canvas overlay and
  reach the page file. The CAN-16 row notes the working-tree implementation but keeps its
  baseline status (see the ADR-002 extension).

- Fixed connection points (2026-11-13): hovering a bindable shape, or dragging a
  connector end over one, marks its eight fixed anchors, the four corners and four edge
  midpoints, with small crosses when the page's connection points setting is on. A
  connector end dropped within 12 screen pixels of an anchor stores that anchor's
  normalized fraction, so the end follows the same corner or midpoint when the shape is
  moved or resized. New arrows snap their start the same way. The CAN-15 row notes the
  working-tree implementation but keeps its baseline status.

- Superscript and subscript (2026-11-16): a text style and each text span can carry a
  script value of normal, super, or sub. The Text tab gains x² and x₂ toggles after S;
  with no text selection they set the whole node's base, and inside a text selection
  they override only the selected characters. Applying one replaces the other, and
  pressing the active toggle returns the range to normal. Superscript and subscript
  glyphs draw at 0.7 of the base size and shift the baseline by -0.35 em and 0.15 em;
  line boxes keep the base size, so only the glyph size, advance, and baseline move.
  Both layout paths apply the same metrics, the value reaches the page file, and clear
  formatting resets it. The TXT-20 row notes the working-tree implementation but keeps
  its baseline status.

- Rotation (2026-11-17): a node stores a clockwise angle and a Keep label upright flag.
  A circular handle above the selection's top-right turns an unlocked single shape or
  empty frame in 15 degree steps, or 1 degree with Shift; the Arrange tab has an exact
  Angle field and a Rotate shape only by 90 degrees button. Dragging and the 90 degree
  button turn the label with the shape unless the flag is set, while the exact field
  follows the flag. Hit testing unrotates the pointer for rotated shapes, the overlay
  draws the handle and stem, and save, load, undo and redo, and PNG, SVG, and draw.io
  export keep the state. Groups, frames with children, and connectors have no handle,
  and draw.io's format has no upright-label style. The SHP-19 row notes the working-tree
  implementation but keeps its baseline status.

- Per-shape connector defaults (2026-11-17): a shape can store the style for connectors started
  from it. The Style tab's Set as source connector default button copies a selected connector's
  style to the shape its line starts from, and the Arrange tab can copy the page connector
  default to selected shapes or clear their source default. Each is one undo step. New arrows
  drawn from a shape, including quick-connect arrows, use the source default before the page
  default; existing connectors keep their own style. The value travels in the page file and in
  the draw.io UserObject sidecar. The CON-19 row notes the working-tree implementation but keeps
  its baseline status (see the ADR-008 extension).

- Embedded pages in SVG and PNG (2026-11-18): PNG and SVG export can carry a native
  bundle of every page, camera, project name, active page id, and image asset. SVG uses
  a metadata element with id sketch-rs-data; PNG uses a tEXt keyword. The Export tab
  has an opt-in Embed pages for reopening checkbox, and the CLI accepts --embed-data.
  Import reads that bundle before the vector importers, so an embedded file reopens as
  editable pages instead of traced artwork. Files exported without the option keep
  their existing carriers. HTML and PDF carriers and draw.io-compatible metadata are
  still absent. The DOC-15 row notes the working-tree implementation but keeps its
  baseline status.

- Collapsible and searchable format sections (2026-11-18): every format section
  has a chevron and a label set. Open and closed state is saved in the app option
  file under inspector_sections, so older files keep all sections expanded and
  a collapse survives restart. A session-only filter above the sections keeps
  matching groups open, hides nonmatching rows, forces collapsed groups open
  while the query is active, and restores saved state when cleared. A query with
  no matches reports that no properties matched. Six inspector tests and the
  options round-trip test cover the behavior. The UIX-04 row notes the
  working-tree implementation but keeps its baseline status.

- Global style schemes (2026-11-18): ten named schemes now apply from the global
  and selected-element Style tabs. Page scope updates eligible nodes and the page
  scheme, background, and grid; selection scope restyles only selected subtrees.
  The command previews and reports what it changes or skips, avoids locked, hidden,
  and group nodes, and keeps rich text, metadata, component overrides, and adaptive
  color pairs. It is one undo step and survives save. draw.io export writes
  sketchScheme and import validates the name. Focused tests and live evidence are
  in `.artifacts/round33/`. The STY-21 row records that verification.

## Status rules

- `VERIFIED` requires a named committed test or a code path that this inventory read and
  that is exercised directly. Screenshots and runtime notes from earlier sessions are
  cited only as supporting context, never as the sole proof of `VERIFIED`.
- `IMPLEMENTED` means the code exists at HEAD but this session did not run a focused
  test. A note that runtime evidence exists in `.opencode/MEMORY.md` is not a claim that
  it was re-run.
- **ANALYZED** means the draw.io behavior is documented and a native design choice is
  recorded in `architecture-decisions.md`, with no implementation. There are no **ANALYZED** rows at HEAD in this round.
- `DISCOVERED` means the capability is documented in draw.io's docs and absent from the
  baseline. `BLOCKED` adds a concrete reason that prevents work now.
- A row with a limitation does not become `VERIFIED` merely because the happy path
  works. The limitation stays visible in the last column.

## Reading a row

IDs are stable within a domain. `DOC` covers projects, pages, and document settings;
`CAN` canvas navigation; `SHP` geometry; `CON` connectors; `TXT` text; `STY` styles;
`ORG` structure; `GEN` generation and diagram types; `IO` files; `CUS` libraries;
`DIA` diagram data; `STO` storage and sharing; `UIX` editor chrome.

The draw.io source is documentation of the behavior, not code that was copied.
Sketch is a clean-room reimplementation and does not include draw.io code, shaders,
icons, fonts, or assets.
